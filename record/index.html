decisions

This record follows the R package decisions from the first brainstorm to the submission of version 0.1.0 to CRAN. It is a subset of the record of a larger project: Beyond CLIP: Calibrated (Few-Shot) Defect Detection With Structured Decision Models. A paper on that project is in progress. Fadel M. Megahed directed the work with Claude Code (Anthropic), which wrote the code, the documentation and the record. The record follows the Claude Code skill replication-materials (Megahed, 2026). The development version of the package installs from GitHub with pak: pak::pak("fmegahed/decisions"). Add dependencies = TRUE to also install the suggested packages that the vignettes use. Then library(decisions) loads the package.
